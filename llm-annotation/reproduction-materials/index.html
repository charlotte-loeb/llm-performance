Analysis Scripts (R)

The following contains the data and the R script for the reproduction of all analyses reported in the manuscript and the SI Appendix. The unit of analysis is the coded variable (n = 17). For each variable, expert ratings of annotation complexity (need for information, need for interpretation) and of the prompts (clarity, completeness) are related to LLM–human reliability (Krippendorff's alpha and percentage agreement) for majority-vote LLM coding, Gemini 3.1 Flash Lite, GPT 5 Nano and Qwen3 235B.

Quick start

  1. Unzip the file and open Analyses_LLM-Human Codings.Rproj (sets the working directory to the project folder).
  2. Install the packages listed under Software below.
  3. Run source("00_MASTER_analysis.R").

All results, tables and figures are written to the folder _output/. It contains only generated files and can be deleted at any time. The input and output folders can be changed without editing the script via the environment variables MEDCON_DATA_DIR and MEDCON_OUT_DIR.

Input data

File Content
exsvy_public.sav Expert survey, public version: 17 experts rate the prompts for 17 variables on need for information, need for interpretation, clarity and completeness (1–5); columns <item><dimension>, e.g. toneinterpret
icr_list1.rds LLM–human reliability per variable: list with res_consensus (majority vote) and res_indiv (one row per model × variable); columns Variable, Level, Krippendorffs_Alpha, Agreement (0–1), and Comparison (model name, res_indiv only)
overview_human_icr.sav Human–human (pre-consensus) reliability per variable: Variable, Human_Kripp_Alpha, Human_Agreement; used for the robustness check in Table S14, Panel C

How icr_list1.rds was produced from the human and LLM codings (prompts, models and API settings, majority vote, reliability computation; SI Appendix S3) is documented on a separate page ([TO FILL: link]).

Manuscript elements and output files

Table numbers are set in the configuration of the master script (SI_TABLE_EXPERT, SI_TABLE_REG, SI_TABLE_ROBUST). Regression blocks: 1 = need for information, 2 = need for interpretation, 3 = both jointly. Parts: A = alpha, B = percentage agreement, C/D = hierarchical models in which Step 2 adds clarity and completeness (alpha / agreement).

Software

R 4.6.1. Packages (versions of the last run in _output/sessionInfo.txt): tidyverse, haven, patchwork (≥ 1.2.0), svglite, scales, modelsummary, flextable, officer, car, irr, psych (uses lme4 for the ICC with missing ratings); sandwich and lmtest for the HC3 standard errors.
